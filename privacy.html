task-hub Privacy Policy

Effective date: 2 November 2026

Who uses this app

task-hub is a personal tool used only by its owner, with the owner's own Google accounts. It is not offered to other users.

What data it accesses

With the owner's permission, task-hub uses read-only Gmail scopes to read message information such as sender, subject, date and labels from the owner's own mailboxes. It cannot send, delete or modify email.

How the data is used

The data is used only to identify emails that need a reply or follow-up and to produce a private task list for the owner. It is not used for advertising, not sold, and not shared with anyone else.

Storage

Only derived task summaries are stored, in a private repository that only the owner can access. Email bodies and attachments are not stored.

Limited Use

task-hub's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
